# Interface guidelines

- Design for a desktop business dashboard.
- Keep screens minimal: concise text, few controls and clear next actions.
- Follow the dashboard patterns and components. Keep spacing, typography and interactions consistent.
- Use compact page headers, pill tabs, and flat sections with dividers. Use the same row layout for settings, lists, and board columns.
- Use borders around interactive controls, upload targets, and dialogs. Use the theme's status colors for feedback and keep source documents in their original appearance.
